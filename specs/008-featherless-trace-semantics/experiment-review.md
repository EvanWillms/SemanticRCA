## Direct checks performed in this review

All 27 S01 output hashes recorded in its manifest match saved files. The recorded fact-diff decision is supported_on_fixture, every recorded passed flag is true, and the manifest reports zero model calls. This independently checks artifact integrity and internal reporting; it does not re-establish every ground-truth fact or human annotation independence.

S01 cold packet sizes are 3,455/3,455/3,645 bytes, versus compact source fixture sizes 1,548/1,548/1,741 bytes. These sources have different metadata contracts, so the ratios are not a fair compression score. No actual GLM token measurements are present. S01 is a normalized graph control, not an implemented motif compressor or learned tokenizer.

## Design findings

1. **Saved packets leak the experimental answer.** `T0.packet.json` and its peers embed `policy.pass_rule`, which names T0/T1 equivalence, the added T2 catalog child and expected preservation. The same policy contains the named hypothesis. Feeding these packets verbatim would contaminate the test. Build inputs from raw authored fixtures plus neutral representation definitions; keep pass rules, fixture relationships and evaluator manifests out of model requests.
2. **Status S09 is a different question.** Its three status-mapping cases do not test the established structural encoding or operation-symbol conversion. For this user's semantic-tokenization request, make P01 the immediate structural prompt probe and retain S09 as a separately defined follow-up. This is a planning amendment, not a reinterpretation of S09 results.
3. **A deterministic control already succeeds.** The experiment must not claim that GLM is needed to map four known operation names or preserve a small graph. Test whether the proposed prompt performs that transformation faithfully; compare latency/cost with the zero-inference deterministic route. A pass demonstrates interface feasibility, not added reasoning value.
4. **Whole-request replay confounds caching attribution.** Repeating the same case can cache its evidence as well as the prompt pack. The separate cache smoke changes the suffix after the shared static prefix and uses a matched target-case control.
5. **The minimal prompt may not qualify for caching.** Count the actual selected-model static prefix before claiming eligibility. Whole-request length and bytes are insufficient. Do not add irrelevant instructions merely to exceed a caching threshold.

Decision: [P01 plus a conditional six-call cache smoke](minimal-test.md). The narrower status test and the previous 12-call caching sketch remain later alternatives, not extra calls hidden inside this protocol.
