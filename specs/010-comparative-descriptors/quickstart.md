# Validation quickstart: Comparative descriptors

These are planned implementation-era commands. The `rca.comparisons` package and its new tests/fixtures are not implemented by this planning task; no acceptance pass is claimed here.

## Prerequisites

- Python 3.12 and the implemented [consumer interface](contracts/consumer.md), with no model credential or third-party package.
- Authored fixture tree `tests/fixtures/comparative_descriptors/` and independently calculated expected outcomes for D01–D12.
- Feature 009's real producer and synthetic dataset for the joint test. Pure tests may use authored baseline objects; the joint test must build a bundle from raw sources.

## Run focused acceptance

```sh
python3.12 -m unittest discover -s tests/unit -p 'test_descriptor_*.py' -v
python3.12 -m unittest discover -s tests/integration -p 'test_comparison_pipeline.py' -v
```

Expected: nonempty suites pass all [D01–D12](acceptance.md), with evidence showing the tested case IDs. Fixtures independently verify +20/−20/zero excess, supported constant/zero centers, all four field states, retained instability, count changes within C1, operation-set nonmatches and unknown versus empty structure.

The source-evidence suite must include parseable pointers that resolve to the wrong entity, raw value or statistic. Merely proving pointer existence or matching output hashes is insufficient. Expected results must not be generated by `describe` or the baseline helper being tested.

## Build from the actual baseline producer

After following the [baseline quickstart](../009-qualified-short-baselines/quickstart.md), use its `BASELINE_RUN_ROOT` in the same shell:

```sh
python3.12 -m rca.comparisons build \
  --dataset-dir tests/fixtures/qualified_baselines/dataset \
  --baseline-dir "$BASELINE_RUN_ROOT/baselines" \
  --output-dir "$BASELINE_RUN_ROOT/descriptors"
python3.12 -m rca.comparisons validate \
  --dataset-dir tests/fixtures/qualified_baselines/dataset \
  --baseline-dir "$BASELINE_RUN_ROOT/baselines" \
  --bundle-dir "$BASELINE_RUN_ROOT/descriptors"
```

Expected: exit 0, validated complete manifest and one descriptor per resolved input assignment. Negative, zero and unavailable outcomes remain in `descriptors.jsonl`; `review.json` references only up to five positive signed excesses per slice. Unsupported references count as valid unavailable outcomes, not omitted requests.

For the producer's constant 10 ms / query 12 ms fixture, the default descriptor contains +2 ms while optional diagnostics are not_requested. Enable optional diagnostics in a distinct output generation:

```sh
python3.12 -m rca.comparisons build \
  --dataset-dir tests/fixtures/qualified_baselines/dataset \
  --baseline-dir "$BASELINE_RUN_ROOT/baselines" \
  --output-dir "$BASELINE_RUN_ROOT/descriptors-with-diagnostics" \
  --diagnostics ratio,mad
```

Expected: the same primary eligibility/excess and review membership; ratio 1.2 and MAD departure undefined with a zero-MAD reason. A zero-center fixture has an available excess but both requested diagnostics undefined. Diagnostics change the definition/descriptor identity and never overwrite the earlier bundle.

## Evidence, structure and coverage inspection

The joint test verifies that every duration field resolves to its original measurement and baseline statistic; each structural delta resolves to an identified C0 pattern with the correct known denominator. Multiple patterns remain available, and unknown references have separate per-C0 counts. An unmatched C1 query can retain structural evidence despite unavailable duration comparison. A query-only C0 first appearing in the final slice retains a typed missing-context outcome and unavailable structural frequency; producer catalog/set/member IDs stay unchanged.

Round-trip complete artifacts and compare values, state/reasons, qualifications, IDs and source links. Exercise repeated observations across windows: unique-observation count differs from occurrence count without losing either. Verify deterministic ties and rank by unrounded excess rather than ratio or displayed rounded values.

Corrupted bundle schema/hash yields input rejection. A localized wrong measurement produces a validation failure and unavailable affected fields, with a nonzero CLI result; it cannot appear in a trusted review as a valid difference. Budget stops preserve completed records and explicit unprocessed counts in a partial generation.
